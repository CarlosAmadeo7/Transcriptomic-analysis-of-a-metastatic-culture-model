# Transcriptomic-analysis-of-a-GP3-metastatic-culture-model
1. In order to study Group3 (GP3) medulloblastoma metastasis in a cell culture model, we cultured GP3 cells in normal media, as control, and in aCSF media (Artificial Cerebrospinal Fluid) to mimetize spinal metastasis. Cells, after a period of incubation, were harvested and sequenced for transcriptomic characterization.
2. This repository contains downstream analysis of the study, including differential expressed genes and over-representation analysis.
